# Limitations and Recovery Plan

This file turns unresolved evidence gaps into an inspection agenda. It distinguishes handled desk-search gaps from claims of exhaustive manuscript-catalogue coverage.

## Consent-Sensitive Access

Private and community-controlled witnesses are recorded as recovery routes, not
as access entitlements. Discovery does not imply permission to inspect, image,
digitize, publish, or pressure access to a manuscript or performance archive.
For the Ilkhchi and related Alevi-community materials, the remaining path is
consent-based collaboration with relevant holders and specialists, with any
future publication or metadata expansion governed by the terms under which
access is granted. CARE, Local Contexts, community-archive protocols, and
cultural-heritage digitization ethics are useful comparator frameworks for this
boundary, but this project does not apply TK/BC labels or any community-governance
vocabulary unilaterally.
